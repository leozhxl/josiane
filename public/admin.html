Integração com a Kiwify

Toda venda aprovada na Kiwify cai automaticamente no funil, na coluna "Fechado".

Verificando conexão…

Selecione os eventos de pedido pago, reembolsado e chargeback na Kiwify. O token de segurança já está incluso na URL acima (configurado no .env como KIWIFY_WEBHOOK_TOKEN).

Verificando API de pagamentos…

Além do webhook, o painel pode consultar diretamente a API oficial de vendas da Kiwify — útil para conferir pagamentos e importar vendas antigas. Gere as credenciais em Kiwify > Configurações > API do desenvolvedor e preencha no .env: KIWIFY_CLIENT_ID, KIWIFY_CLIENT_SECRET e KIWIFY_ACCOUNT_ID.
